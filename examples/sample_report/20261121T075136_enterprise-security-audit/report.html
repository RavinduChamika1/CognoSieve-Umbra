Framework Tags: OWASP LLM01:2025 Model Denial of Service, OWASP LLM02:2025 Sensitive Information Disclosure, NIST AI RMF MAP 1.1 (AI System Context & Asset Inventory), NIST AI RMF MEASURE 2.6 (Security & Resiliency), NIST AI RMF MEASURE 2.6

Remediation Steps:
  1. Set OLLAMA_HOST=127.0.0.1:11434 in environment or service configuration.
  2. Upgrade to Ollama >= 0.1.34 to patch CVE-2024-37032.
  3. Do not expose Ollama port 11434 to untrusted networks without an authenticating reverse proxy.
  4. Enable API key or bearer token authentication in the service configuration.
  5. Place an authenticating reverse proxy (e.g., Caddy, Envoy, LiteLLM with master key) in front of the listener.
  6. Audit and restrict model listing endpoints (/v1/models, /api/tags) to authenticated callers.
  7. Remove unapproved or proprietary fine-tuned model weights from public storage directories.
  8. Review this discovery with the security/compliance team. Add to approved.yaml if legitimate, or decommission.
